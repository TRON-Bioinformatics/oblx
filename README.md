# TronMake Genome Lib Builder

The TronMake Genome Lib Builder is a resource collection used by TronMake pipelines. This TronMake Genome Lib Builder system is leveraged for preparing a reference genome and annotation set 
for use with TronMake pipelines, including cancer-specific alternative splicing and somatic mutation discovery. The genome resource building process creates a 'Genome lib' for different pipelines.
