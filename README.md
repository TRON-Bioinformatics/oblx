The TronMake Genome Lib Builder is a resource collection used by NGS analysis pipelines developed by the computational medicine group at [TRON](https://github.com/TRON-Bioinformatics). This TronMake Genome Lib Builder system is leveraged for preparing a reference genome and annotation set for use with SnakeMake and NextFlow based pipelines, including cancer-specific alternative splicing and somatic mutation discovery. The genome resource building process creates a unifiied 'Genome library' based on GENCODE reference annotation and the GATK resource bundle (hg38).

The following pipelines are compatible with the TRON Genome Lib:

- TronFlow pipelines
