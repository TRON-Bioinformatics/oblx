# Licenses

This [OBLX](https://github.com/TRON-Bioinformatics/oblx) generated library
contains resources from different origins. Please review the applicable licenses
and terms of use before using or redistributing this bundle.

We acknowledge and attribute all providers of the datasets included in this
bundle. Information on the specific terms of use of each resource can be found
below.

## UniProt

UniProt (The UniProt Consortium, 2025) is licensed under **CC BY 4.0** (see
[https://www.uniprot.org/help/license](https://www.uniprot.org/help/license)).

## dbSNP

dbSNP (Phan et al., 2025) is licensed under ODbL v1.0
([https://catalog.data.gov/dataset/dbsnp](https://catalog.data.gov/dataset/dbsnp)).

## GENCODE

The data access statement for GENCODE (Mudge et al., 2025) can be found here:
[https://www.gencodegenes.org/pages/data_access.html](https://www.gencodegenes.org/pages/data_access.html)

## gnomAD

Usage policies for gnomAD (Karczewski et al., 2020) can be found here:
[https://gnomad.broadinstitute.org/policies](https://gnomad.broadinstitute.org/policies).

## TCGA viral sequences

TCGA viral sequences were downloaded from GenBank (Clark et al., 2016). For data
usage policy see
[https://www.ncbi.nlm.nih.gov/genbank/](https://www.ncbi.nlm.nih.gov/genbank/).

## 1000 Genomes

Data from the 1000 Genomes project (The 1000 Genomes Project Consortium, 2015)
was downloaded from the
[GATK bundle](https://gatk.broadinstitute.org/hc/en-us/articles/360035890811-Resource-bundle)
and thus reflects the state of the dataset in the GATK bundle, which does not
ensure the latest version of the data (see NLM copyright information:
[https://www.nlm.nih.gov/databases/download.html](https://www.nlm.nih.gov/databases/download.html)).

## HapMap

The HapMap data were also downloaded from the
[GATK bundle](https://gatk.broadinstitute.org/hc/en-us/articles/360035890811-Resource-bundle).
The official website of the HapMap Project was maintained by the U.S. National
Center for Biotechnology Information (NCBI). The institute ceased updating the
data in June 2016, as traffic to the website and the data had been declining
since 2011. Instead, NCBI refers users to the 1000 Genomes Project, which can be
considered its successor. For copyright information see 1000 Genomes section.

## Mills

Indel variants from Mills et al. (2011) were downloaded from the
[GATK bundle](https://gatk.broadinstitute.org/hc/en-us/articles/360035890811-Resource-bundle).
The indels from the publication were also updated to dbSNP, see section dbSNP
for license information.

## Problematic regions / Exclusion lists

Exclusion lists from ENCODE (Amemiya et al., 2019), from GRC (Behera et al.,
2022\) and problematic regions from UCSC were downloaded from the UCSC Genome
Browser (Casper et al., 2026). For license information see
[https://genome.ucsc.edu/license/](https://genome.ucsc.edu/license/).

## RepeatMasker

The repeats annotated with RepeatMasker v3.0.1 were downloaded from UCSC (Casper
et al., 2026). For license information see
[https://genome-euro.ucsc.edu/cgi-bin/hgTrackUi?&db=hg38&g=rmsk](https://genome-euro.ucsc.edu/cgi-bin/hgTrackUi?&db=hg38&g=rmsk).

## TWIST

TWIST exome probesets were downloaded from the UCSC Genome Browser (Casper et
al., 2026).

> Note: Twist exome probesets are not under a permissive license. It is thus not
> provided in the
> [pre-built OBLX library](https://tron-bioinformatics.github.io/oblx/#pre-built-indices).
> Please check for your specific use case.

For further license information see
[https://genome.ucsc.edu/license/](https://genome.ucsc.edu/license/).
